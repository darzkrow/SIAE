🔄 Flujo de Aprobación con QR Codes NUEVO

Secuencia completa del proceso de aprobación dual mediante escaneo de códigos QR.

Proceso: Crear solicitud → Generar QR → Aprobar Origen (QR) → Aprobar Destino (QR) → Ejecutar traslado automático 
sequenceDiagram
    participant U as Usuario
    participant F as Frontend
    participant A as API
    participant Q as QRGenerator
    participant D as Database
    participant M as Mobile
    
    U->>F: Crear Solicitud Traslado
    F->>A: POST /solicitudes-traslado/
    A->>D: Guardar Solicitud
    D-->>A: Solicitud Creada
    
    A->>Q: generar_qr_code()
    Q->>Q: Crear URL aprobacion
    Q->>Q: Generar imagen QR
    Q->>D: Guardar QR en media
    D-->>Q: QR guardado
    Q-->>A: QR generado
    
    A-->>F: Solicitud mas QR URL
    F-->>U: Mostrar QR Code
    
    Note over U,M: Gerente Origen escanea QR
    
    M->>M: Escanear QR Code
    M->>A: POST aprobar-origen
    A->>D: Validar permisos
    D-->>A: Usuario autorizado
    A->>D: Crear Aprobacion ORIGEN
    A->>D: Estado APROBADA_ORIGEN
    D-->>A: Actualizado
    A-->>M: Aprobacion exitosa
    
    Note over U,M: Gerente Destino escanea QR
    
    M->>A: POST aprobar-destino
    A->>D: Validar estado
    A->>D: Crear Aprobacion DESTINO
    A->>D: Estado APROBADA_COMPLETA
    A->>D: Ejecutar traslado
    D-->>A: Traslado ejecutado
    A-->>M: Aprobacion completa

💾 Flujo de Datos Completo

Flujo completo desde la creación de solicitud hasta la ejecución del traslado.

Importante: Este flujo muestra todos los pasos críticos del sistema, incluyendo validaciones y actualizaciones de estado. 
flowchart TD
    Start([Usuario crea solicitud]) --> A[Frontend: Formulario]
    A --> B[API: POST solicitudes]
    B --> C{Validar datos}
    C -->|Error| D[Retornar 400]
    C -->|OK| E[Crear SolicitudTraslado]
    
    E --> F[Generar QR Code]
    F --> G[Crear URL de aprobacion]
    G --> H[Generar imagen QR]
    H --> I[Guardar en media]
    I --> J[Actualizar solicitud]
    
    J --> K[Retornar solicitud]
    K --> L[Frontend: Mostrar QR]
    
    L --> M{Gerente Origen escanea}
    M --> N[Mobile: Leer QR URL]
    N --> O[API: POST aprobar-origen]
    O --> P{Validar permisos}
    P -->|No autorizado| Q[403 Forbidden]
    P -->|Autorizado| R[Crear Aprobacion ORIGEN]
    
    R --> S[Estado APROBADA_ORIGEN]
    S --> T[Notificar gerente destino]
    
    T --> U{Gerente Destino escanea}
    U --> V[API: POST aprobar-destino]
    V --> W{Validar estado}
    W -->|Error| X[400 Bad Request]
    W -->|OK| Y[Crear Aprobacion DESTINO]
    
    Y --> Z[Estado APROBADA_COMPLETA]
    Z --> AA[Ejecutar traslado automatico]
    AA --> AB[Actualizar almacen_actual]
    AB --> AC[Crear HistorialMovimiento]
    AC --> AD[Estado COMPLETADA]
    
    AD --> End([Traslado completado])
    
    style Start fill:#667eea,color:#fff
    style End fill:#28a745,color:#fff
    style F fill:#ffc107,color:#000
    style AA fill:#dc3545,color:#fff
