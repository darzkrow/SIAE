🔄 Flujo de Aprobación con QR NUEVO

Proceso de aprobación dual mediante QR.

Proceso: Crear → Generar QR → Aprobar Origen → Aprobar Destino → Ejecutar 
sequenceDiagram
    participant U as Usuario
    participant F as Frontend
    participant A as API
    participant Q as QRGenerator
    participant D as Database
    participant M as Mobile
    
    U->>F: Crear Solicitud
    F->>A: POST /solicitudes/
    A->>D: Guardar
    D-->>A: ID Creado
    
    A->>Q: generar_qr_code()
    Q->>Q: Crear URL
    Q->>Q: Generar QR
    Q->>D: Guardar QR
    D-->>Q: OK
    Q-->>A: QR generado
    
    A-->>F: Solicitud + QR
    F-->>U: Mostrar QR
    
    Note over U,M: Escanear QR Origen
    
    M->>A: POST /aprobar-origen/
    A->>D: Validar
    A->>D: Crear Aprobacion
    D-->>A: OK
    A-->>M: Aprobado
    
    Note over U,M: Escanear QR Destino
    
    M->>A: POST /aprobar-destino/
    A->>D: Validar
    A->>D: Ejecutar Traslado
    D-->>A: Completado
    A-->>M: Traslado OK

🎯 Máquina de Estados

Ciclo de vida de solicitudes de traslado.

stateDiagram-v2
    [*] --> PENDIENTE
    
    PENDIENTE --> APROBADA_ORIGEN: Aprobar Origen
    PENDIENTE --> RECHAZADA: Rechazar
    
    APROBADA_ORIGEN --> APROBADA_DESTINO: Aprobar Destino
    APROBADA_ORIGEN --> RECHAZADA: Rechazar
    
    APROBADA_DESTINO --> APROBADA_COMPLETA: Validar
    
    APROBADA_COMPLETA --> EN_TRANSITO: Ejecutar
    
    EN_TRANSITO --> COMPLETADA: Confirmar
    
    RECHAZADA --> [*]
    COMPLETADA --> [*]
